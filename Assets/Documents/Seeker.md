# シーカー：Unity エディタでの作業

シーカーのスクリプトは実装済みです。動かすには、以下のエディタ作業が必要です。

## 1. 立ち位置の Transform を置く（MainGame シーン）

1. MainGame シーンで、盤面の奥（右側の外）に空の GameObject を作る。名前は `SeekerStandPoint` など。
2. シーカーを立たせたい位置に動かす。シーカーは盤面のマスを占有しないので、盤面の外で構いません。
3. `UnitSpawner` コンポーネントの **Seeker Stand Point** に、この GameObject を割り当てる。

未設定の場合は、ステージCSVで指定したマスにそのまま表示され、コンソールに警告が出ます。

## 2. アニメーター（Addressables）

1. `Assets/Addressables/Animator/Seeker.controller` を作り、Addressables に登録する。アドレスは他の敵と同じく `Assets/Addressables/Animator/Seeker.controller`。
2. 召喚モーションのステートを作り、トリガー `SkillT` で遷移させる。
3. 召喚モーション（`Assets/Animation/seeker/Skill.anim`）の、フラスコが手から離れるフレームに、アニメーションイベントで `ThrowFlask` を呼ぶ。召喚するフェーズでは、ここで召喚先のマスへフラスコが飛びます（バフのフェーズでは何も起きません）。
4. 召喚モーションの最後に、アニメーションイベントで `ActiveAttack` を呼ぶ。これが呼ばれるまで召喚処理は始まりません。

`ThrowFlask` のイベントが無い場合は、モーションの後に立ち位置からフラスコを投げます。

アニメーターが無い場合は、モーションを待たずに召喚します（止まらないようにしてあります）。

## 3. 見た目

- スプライトの高さ合わせは `Assets/Addressables/EnemyInfo.csv` の ID 7 の行（Offset / TopDownOffsetY）で調整できます。
- シーカーは攻撃を受けないので、HPゲージは不要なら非表示にしてください（現状は他の敵と同じプレハブを使うため表示されます）。

## 3.5 フラスコ

召喚するフェーズでは、シーカーが召喚先のマスへフラスコを投げ、全部のフラスコが着地してからそのマスにエナーが現れます。

### フラスコのプレハブを作る

1. `Assets/prefab/` にフラスコのプレハブ（例: `Flask.prefab`）を作る。見た目は SpriteRenderer など自由です。
2. ルートに `FlaskObject` を付ける。
   - Animator: フラスコのアニメーター（任意）。
   - Flight Duration: 投げてから着地するまでの秒数（既定 0.6）。
   - Jump Power: 放物線の高さ（既定 2）。
3. アニメーターを使う場合
   - 投げた瞬間から既定のステート（回転など）が最初から再生されます。
   - 着地した瞬間に、トリガー `LandT` があれば引きます（割れる・開くなどのステートへ遷移させる）。
   - フラスコのアニメーションの最後に、アニメーションイベントで `OnFlaskAnimationEnd` を呼ぶ。これが来て、かつ着地していればプールへ戻ります。
   - イベントが来ない場合も、着地から5秒でプールへ戻ります（警告ログが出ます）。
4. アニメーターを使わない場合は、着地と同時にプールへ戻ります。

### MainGame シーンに置く

1. 空の GameObject `FlaskPool` を作り、`FlaskPool` を付ける。
   - Object To Pool → 作ったフラスコのプレハブ
   - Init Size → 3（1回に投げる最大本数）
2. 空の GameObject `FlaskThrower` を作り、`FlaskThrower` を付ける。
   - Flask Pool → 1 の `FlaskPool`
   - Release Offset: シーカーの位置から見た、フラスコが手から離れる位置（既定 (0, 1, 0)）
   - Landing Height: 着地するマスの床からの高さ（既定 0.25）
   - Throw Interval: 複数投げるときの1本ごとの間隔（既定 0.1 秒）

`FlaskThrower` が無い場合は、フラスコを投げずに今までどおりエナーが現れます。

## 4. ステージCSVへの配置

ウェーブCSVに、他の敵と同じ形式で1行追加します。

```
Unit,<h>,<w>,Seeker
```

- `<h>,<w>` はエナーを召喚する基準のマスです。シーカーが召喚するときは、このマスに近い空きマスから順にエナーを1〜3体召喚します。盤面の奥（右端の列）を指定するのがおすすめです。
- このマスはシーカーが占有しないので、召喚先にもなります。
- シーカーは倒す対象ではないので、全滅条件の「残りの敵」には数えられません。召喚されたエナーは数えられます（召喚されるたびに残り数が増えます）。

## 仕様と実装の対応

| 仕様 | 実装 |
|---|---|
| 奥地から移動しない、攻撃しない | 盤面外に立ち、移動量0・攻撃なし。マスを占有せず一閃も当たらない（当たり判定オフ・無敵） |
| 毎フェーズ、召喚かバフのどちらかを行う | 毎エネミーフェーズの最初（行動順「前」、盤面上の敵より先）に行う。盤面上のエナーが2体未満なら召喚。2体以上なら (5 - エナー数) / 5 の確率で召喚し、それ以外はバフ |
| 召喚 | エナーを1〜3体召喚する。召喚先へフラスコを投げ、着地したマスにエナーが現れる。召喚されたエナーもそのフェーズに盤面上の敵と一緒に動く |
| 召喚レベル | エナーを2体召喚するごとに、召喚するレベルを+1する（最初はレベル0＝補正なし。シーカーごとに数える） |
| バフ（重複する） | 盤面上のエナー全員に「攻撃+5 / 防御+3 / 移動量+1」のどれか1つ（等確率）。期限なしで重ねがけされる |
| マスターデータ（HP/攻撃/防御/移動量 0） | HP だけ 1（0 だと最初から死亡扱いになるため。無敵なので減りません） |
