# マグネティックコアの効果範囲表示

マグネティックコアを選んで床マスを選んでいる間、**カーソルの下のマスを中心に効果範囲を床に表示**するようにしました。カーソルを動かすと範囲も追従します。

- 効果範囲は中心マスからマンハッタン距離 3 以内（`MagneticCore.EffectRadius`）。実際の効果と同じ判定を使っています。
- 色は3種類です（見た目は仮。差し替え方は下記）。
  - 中心（使用するマス）: 明るい青
  - 効果範囲のマス: 薄い青（エナジー色 `#3e77dd`）
  - 引き寄せられる敵がいるマス: オレンジ（2x2 のでかエナーは4マスとも塗ります）
- カーソルが盤面の外にあるときは表示を消し、**その状態で左クリックしても使用しません**（今までは盤面外をクリックするとエナジーだけ減って何も起きませんでした）。
- 左クリックで使用した瞬間・右クリックで戻ったときに表示を消します。

## シーン作業（任意）

**何もしなくても動きます。** シーンに `MagneticCoreRangeView` が無い場合は、初めて表示するときに既定の見た目（白い四角のスプライトを色付け）で自動生成します。

見た目を調整したい場合だけ、MainGame シーンに空の GameObject（例: `MagneticCoreRange`）を作り、`MagneticCoreRangeView` を付けてください。

| 項目 | 既定値 | 内容 |
|---|---|---|
| Tile Prefab | なし | 1マス分のタイル。未設定なら白い四角のスプライトを自動で作る |
| Range Color | (0.24, 0.47, 0.87, 0.35) | 効果範囲のマスの色 |
| Target Color | (1, 0.55, 0.15, 0.6) | 引き寄せられる敵がいるマスの色 |
| Center Color | (0.45, 0.75, 1, 0.75) | 使用するマスの色 |
| Height Offset | 0.02 | 床からの高さ。床とチラつく場合は少し上げる |
| Tile Scale | 0.92 | タイルの大きさ（1 で1マスぴったり） |
| Sorting Order | -4 | SpriteRenderer の Sorting Order。敵やエナジーウォール（-3）より奥に描く |

### タイルの見た目を差し替える

`Tile Prefab` に好きなプレハブを入れると、そのプレハブを1マスごとに並べます。

- プレハブは **XY 平面で 1×1 の大きさ**に作ってください（床に寝かせるため、X 軸 90° 回転で置きます）。中心が原点。
- 子に `SpriteRenderer` があれば `color` に上の色を入れます。無ければ `Renderer` のマテリアルの `_BaseColor` / `_Color` に入れます（URP Unlit の Transparent など、アルファが効くマテリアルにしてください）。
- 色を変えたくない（プレハブの色のまま使いたい）場合は、各色を白 (1,1,1,1) にしてください。

## 確認してほしいこと

- マグネティックコアを選んで床マスを選ぶとき、カーソルの下を中心にひし形の範囲が出て、カーソルに付いてくる
- 範囲内の敵のマスがオレンジになる（でかエナーは基準マスが範囲内なら4マスとも）
- 盤面外にカーソルを出すと表示が消え、クリックしても使用されない
- 左クリックで使用すると表示が消えて敵が引き寄せられる。右クリックで装備選択に戻っても表示が消える
- タイルが床に埋もれたり、敵の手前に描かれたりしないか（した場合は Height Offset / Sorting Order を調整）
