# 床ギミック（ワープホール・リエイムパッド）のシーン設定

ステージ CSV に置いた床ギミックを、ウェーブの読み込み時に盤面へ置くようにしました。
仕様は Notion の「1-3-1. ワープホール」「1-3-2. リエイムパッド」を参照してください。

## 1. ステージ CSV の書き方

```
WarpHole, 縦, 横, ペア番号
ReAimPad, 縦, 横
```

- 同じペア番号のワープホール2つが対になります。番号が1つしか無い・3つ以上ある場合は、そのペアは何も起きません（Console に警告が出ます）。
- ほかの壁・敵と同じマスには置けません（ステージエディタでも、CSV の読み込みでも重複は弾かれます）。
- ステージエディタ（Tools > Stage > Stage Editor）では、マスの種類「4: ワープホール」「5: リエイムパッド」で置けます。ペア番号は「マスの詳細」で変えられます。

## 2. ワープホール・リエイムパッドのプレハブ

1. 見た目（ワープホールはエフェクト、リエイムパッドはモデル）を置いた GameObject を作り、ルートに `WarpHoleView` / `ReAimPadView` を付けてプレハブにする。
   - ピボット（ルートの位置）を **マスの中心・床の高さ** に合わせる。
2. 一閃が入ったかの判定用にコライダーを付ける（子でもよい）。
   - 一閃の線がコライダーに入った瞬間にワープ・リエイムします。円形にしたいなら Capsule / Mesh コライダーなど、形は自由です。
   - 高さはプレイヤーと合っていなくても大丈夫です（コライダーの中心の高さで判定します）。
   - 実行時に自動で **Is Trigger: オン**、レイヤー **Ignore Raycast** になります（壁の判定やポインターのレイキャストに当たらないように）。
3. `WarpHoleView` / `ReAimPadView` のインスペクターで以下を割り当てる。

| フィールド | 割り当てるもの |
|---|---|
| Colliders | 2. のコライダー |
| Material | エフェクト・モデルのマテリアル（**Surface Type: Transparent**、色は `_BaseColor`） |
| Renderers | そのマテリアルを使う Renderer（パーティクルなら ParticleSystemRenderer、モデルなら MeshRenderer） |
| Used Alpha | 使用済みのときの不透明度（既定 0.3） |

4. MainGame シーンに空の GameObject を作り、`FloorGimmickManager` を付けて、**Warp Hole Prefab** / **Re Aim Pad Prefab** にプレハブを割り当てる。
   - **シーンに置かないと床ギミックは置かれません**（CSV に書いてあれば Console に警告が出ます）。プレハブ未設定のときも警告が出ます。
   - **Height Offset**: 床と重なってチラつく場合は少し上げる。

## 3. 使用済みの半透明

ワープホールはペアで1ターンに1回、リエイムパッドは1回の一閃で1回だけ使えます。使うと半透明になり、次のプレイヤーフェーズの開始で元に戻ります。

半透明は、**Material** をギミック1つごとに複製して **Renderers** に割り当て、その `_BaseColor` の α を **Used Alpha** 倍にして行います（Renderer にもともと付いているマテリアルは、複製で置き換わります）。複製はギミックが消えるとき（ウェーブの切り替えなど）に破棄します。

## 4. 動きの確認

- 反射の剣（通常・めちゃくちゃ早い一閃とも）で、一閃がワープホールに入ると対のワープホールの中心から、入ったときの向きのまま出る。
- ワープは【反射回数】を使わない。ダメージ計算の反射数にも数えない。
- 角度選択中の予測線は、ワープの出口の先まで描かれる（入口までで線が切れ、出口から続く）。
- 使ったペアは半透明になり、同じターンにもう一度通っても素通りする。
- 一閃がリエイムパッドに触れると、パッドの中心まで寄ってから止まり、見下ろしカメラになる。
  - 一閃の角度選択と同じく、ポインターを向けてクリックで発射する。予測線は残りの反射回数ぶん出る。右クリックのキャンセル・剣の持ち替えはできない。
  - 発射すると一閃中の追尾カメラに戻る。残りの反射回数・コンボ・反射数ボーナス・分度器QTEの縮み具合はそのまま。
  - 反射回数を使い切った後（分度器QTEで追加反射した後など）に触れても選び直せる。反射回数は0のままで、壁に当たれば分度器QTEになる。
- 角度選択中の予測線は、リエイムパッドの中心で止まる。
- 貫通・弧曲の剣では何も起きない（今は考慮しない）。
- 敵はワープホール・リエイムパッドのマスを普通に通過できる。エナジーウォール・ビルダーの壁・シーカーの召喚は、これらのマスには置かれない。
