# 防御・回復のカメラ演出とパーティクルのシーン設定

防御・回復を選んだとき、装備品と同じようにカメラがプレイヤーへ寄り、専用のパーティクルを再生し、再生が終わったらカメラが元の位置に戻るようにしました。
パーティクルはスクリプトから作れないため、MainGame シーンで以下の設定が必要です。
**パーティクルを割り当てない場合は、カメラが寄ってすぐ戻るだけになります（エラーにはなりません）。**

## 流れ

1. 防御・回復の効果を反映（エナジー加算・HP回復など）
2. カメラをプレイヤーへズーム（装備品ボタンと同じ `ActPlayerWeaponZoom`）
3. 専用パーティクルを再生し、子パーティクルも含めて全て消えるまで待つ
4. カメラを元の位置に戻す（装備品キャンセル時と同じ `ActResetCameraTargetWithRotate`）
5. 「防御の構えをとった」「HPが◯回復した」のメッセージを表示

## 1. パーティクルの作成

1. `Assets/Scenes/MainGame.unity` を開く。
2. `PlayerView` が付いている GameObject（プレイヤー）の子に、Effects > Particle System を2つ作る。
   - 名前の例: `DefendParticle`、`HealParticle`
   - 位置はプレイヤーの足元〜中心あたり。
3. それぞれの Particle System の Main モジュールで以下を設定する。
   - **Looping: オフ**（オンだと終わりが判定できず、最大5秒で打ち切られます）
   - **Play On Awake: オフ**（シーン開始時に再生されないように）
   - Duration と Start Lifetime で演出の長さを決める（合計 1〜2 秒程度がおすすめ）。
4. 見た目の例（自由に変えてOK）
   - 防御: ベースカラー `#3e77dd` の盾・六角形のような粒子をプレイヤー周りに広げる。
   - 回復: 緑〜白の粒子を足元から上へ舞い上がらせる。
5. 子に別のパーティクルを入れても、子も含めて全て消えるまで待ちます。

## 2. PlayerView への割り当て

1. プレイヤーの `PlayerView` コンポーネントを選ぶ。
2. インスペクターで以下を割り当てる。

| フィールド | 割り当てるもの |
|---|---|
| Defend Particle | `DefendParticle` |
| Heal Particle | `HealParticle` |

## 確認ポイント

- 防御・回復ボタンを押すとカメラがプレイヤーへ寄り、パーティクルが消えてからカメラが戻るか。
- カメラが戻ったあとにメッセージが出て、エネミーフェーズへ進むか。
