# クリア条件「特定のボスを撃破する」

## 概要

仕様: Notion「1-メインゲーム」のクリア条件（ボス＝特定敵撃破）

指定した敵を倒すとウェーブクリアになる条件です。
他の敵が盤面に残っていてもクリアになります（『シーカー』のように倒せない敵がいるウェーブ向け）。

Scene の編集は不要です。ウェーブCSVの1行目だけで使えます。

## CSV の書き方

ウェーブCSVの1行目（クリア条件の行）に、条件種別 `3` とボスの敵IDを書きます。

```
3, ボスの敵ID
```

- 条件種別の `3` は `StageClearConditionType.DefeatBoss` の値です（`0`=全滅、`1`=耐久、`2`=連続撃破、`3`=ボス撃破）。
- ボスの敵IDは `Assets/Addressables/EnemyInfo.csv` の ID です。

| 敵ID | 敵 |
| --- | --- |
| 1 | スカイア |
| 2 | ビルダー |
| 3 | ブースター |
| 4 | ブルート |
| 5 | エナー |
| 6 | でかエナー |

例（でかエナーを倒すとクリア）:

```
3, 6
Unit, 4, 14, BigEnar
Unit, 2, 12, Enar
```

敵IDが空・不正なときは、警告ログを出して「どの敵を倒してもクリア」として扱います（クリアできないウェーブになるのを避けるため）。

## 画面の表示

目標表示は「残りのボスはあと 1」で始まり、対象のボスを倒すと 0 になってクリアになります。

## 確認してほしいこと

- 対象のボス以外を倒しても、目標表示が 1 のままでクリアにならないか。
- 対象のボスを倒したときに、他の敵が残っていてもクリアになるか。
- 次のウェーブがある場合は次のウェーブへ進み、最後のウェーブならクリア演出（報酬・続ける/休む）が出るか。
