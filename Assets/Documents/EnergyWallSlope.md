# エナジーウォール（斜面）

## 概要

エナジーウォールを、1マスの対角線に沿った「斜面の壁」に変更しました。
一閃は斜面の法線に沿って反射します（反射型は90度向きが変わる）。

## 操作

1. 装備品からエナジーウォールを選び、床マスを左クリックする
2. 選んだマスに半透明の斜面（プレビュー）が出る
3. マウスホイールの回転、またはホイールの押し込みで向き（／ ⇔ ＼）を切り替える
4. 左クリックで確定（ここでエナジーを消費）、右クリックで取り消してマス選択に戻る（エナジーは消費しない）

前回選んだ向きが、次に使うときの初期値になります。
すでに何かがあるマスを選んだ場合は、プレビューを出さずにマス選択に戻ります。

## 仕組み

- 斜面のメッシュは `SlopeWallMeshBuilder` がコードで生成します（厚さ0.12、高さ1の薄い板）。
- `SlopeWallView` を壁（`BuildingView`）に実行時に追加し、元のキューブの Renderer / Collider を無効化して、斜面の子オブジェクト `EnergyWallSlope`（MeshFilter / MeshRenderer / MeshCollider）に切り替えます。
  - マテリアルとレイヤーは元の壁（`prefab/blocks/energy.prefab`、レイヤー Block）からコピーします。
  - 壁のプールはビルダーの壁と共有しているため、プールへ返す前に元のキューブへ戻します。
- 貫通（通常・高速）で斜面を通り抜けるときは、法線の逆方向へ1マスではなく、進行方向へ板の厚さ分だけ進みます。
- 弧曲は、斜めの面に当たったときだけ法線に沿って反射します（従来の軸ごとの反転では斜面で破綻するため）。

## Sceneの編集

**必須の作業はありません。** プレハブやシーンを変更しなくても動きます。

任意で行うと良いこと:

- **斜面の色を変えたい場合**: `prefab/blocks/energy.prefab` の MeshRenderer のマテリアルを差し替えてください。斜面はそのマテリアルを使います。
- **プレビューを半透明にしたい場合**: プレビューは URP のマテリアルの `_BaseColor` のアルファを半分にして表示します。マテリアルの Surface Type が Opaque だと半透明になりません。半透明にしたい場合は Surface Type を Transparent にしてください。
- **操作説明を出したい場合**: MainGame シーンの `OperateInfos` に、向き選択用の操作説明（「ホイール: 向き変更 / 左クリック: 決定 / 右クリック: 戻る」）を追加してください。現在は `PhaseKinds` に向き選択用の値が無いため、追加する場合は `PhaseKinds` に値を足し、`EnergyWall.SelectDirectionAsync` の冒頭で `OperateInfos.Instance.SetOperateInfo(...)` を呼んでください。

## 確認してほしいこと

- 真上視点で ／ と ＼ が見た目どおりの向きになっているか。逆になっていたら `SlopeWallMeshBuilder.Build` の `along` の2つのベクトルを入れ替えてください。
- MainGame シーンには `WallStack` が2つ（ビルダー用の `brick_generate` と、エナジーウォール用の `energy`）あり、`EnergyWallManager` は `FindObjectsByType<WallStack>` の先頭を使っています。どちらのプレハブで斜面が作られるかは見つかった順番次第なので、色が想定と違う場合はここを確認してください（今回の変更前からの挙動です）。
