# ステージエディタ

## 概要

ステージ（ウェーブ）構築用 CSV の中身を、盤面の図で確認・編集するエディタ拡張です。
Scene / Prefab の編集は不要です。

メニュー **Tools > Stage > Stage Editor** から開き、「ステージCSV」欄に CSV をドラッグ＆ドロップします。

## 画面

### 盤面（上段）

盤面は 9 × 16 マス（`MapManager.MapHeight` × `MapManager.MapWidth`）の byte 配列として表示します。
左の数字が縦（h）、上の数字が横（w）です。ゲーム画面と同じ向きになるよう、縦は上が大きい値（奥）です。

| 値 | 色 | 意味 |
| --- | --- | --- |
| 0 | 黒 | 空 |
| 1 | 灰 | 通常の壁（`Wall`） |
| 2 | 青緑 | スロープの壁（`SlopeWall`）。マスの下に角度を表示 |
| 3 | 赤 | 敵（`Unit`）。マスの下に敵の名前とレベルを表示。でかエナーは 2×2 マスが 3 になる |

『シーカー』のような盤面外の敵はマスを占有しないため、盤面の下の「盤面外のユニット」にボタンで並びます。

ウィンドウの最上部（CSV 欄のすぐ下）の「クリア条件（1行目）」で、クリア条件を変更できます。

| 種類 | 値 |
| --- | --- |
| 0: 全滅 | なし（0 で保存） |
| 1: 耐久 | 耐久ターン数 |
| 2: 連続撃破 | 連続撃破数（ゲーム側が未実装のため全滅として扱われます） |
| 3: ボス撃破 | ボスの敵（倒せないシーカーは選べません）。盤面にその敵がいないと警告が出ます |

### ターン（盤面の上）

「←」「→」で、エネミーフェーズを N 回終えたあとのユニットの配置を表示します（「ターン:0」が CSV のままの配置）。

- 移動先の決め方は `BaseUnit.TryMoveByScoreMap`、行動順は `MapManager.MoveUnit`（横→縦の昇順）と同じです。
- バフ（ブースターの笛など）は考慮しません。移動量は EnemyInfo.csv の Move のままです。
- ランダムな特殊行動（スカイアの飛行、ビルダーの壁生成、シーカーの召喚、エナーの吸収など）と、一閃による撃破は考慮しません。
- ユニットを選んだままターンを進めると、初期位置のマスが薄い赤で表示されます。

### マスの詳細（下段）

盤面のマスをクリックすると、そのマスの詳細が出ます。

- **種類**: 0〜3 を切り替えると、そのマスの配置が変わります（ターン:0 のときだけ）。
- **1（通常の壁）**: 情報なし
- **2（スロープの壁）**: 角度（45 / 135 / -135 / -45）を選べます
- **3（敵）**: どの敵かを選べます（ターン:0 のときだけ）。レベルは変更でき、レベル補正後のステータス（HP・攻撃・防御・移動・行動順・エナジー・経験値・サイズ）が表示されます。ステータスは変更できません（EnemyInfo.csv を書き換えてください）。
  - レベル 0 は補正なし（EnemyInfo.csv の値そのまま）です。補正式はゲームと同じ `EnemyStatusLoader.ParseStatus` を使っています。
  - **行動リスト**: 敵の行動を「攻撃」「スキル」で並べられます（ターンに関係なく編集できます）。下の「行動リスト」を参照してください。

### 行動リスト

敵ごとに、エネミーフェーズの行動を先頭から順に指定できます。

- 「＋ 攻撃」「＋ スキル」で末尾に追加、プルダウンで種類を変更、「↑」「↓」で並べ替え、「×」で削除します。
- エネミーフェーズごとに先頭から1つずつ行い、**使い切ったら今までどおりのランダムな行動**に戻ります。リストが空なら最初からランダムです。
- 「攻撃」はプレイヤーへの攻撃です。普段は隣接（横 0）したときしか攻撃しない敵（ビルダー・ブースター・エナーなど）も、その場から攻撃します。
- 「スキル」は各敵の特殊行動（スカイアの飛び上がり、ビルダーの壁生成、ブースターの笛、シーカーの召喚／強化など）です。
- 行動の順番（移動の前か後か）は今までどおり EnemyInfo.csv の行動順に従います。移動はリストに関係なく毎フェーズ行います。
- ターンを進めると、次のエネミーフェーズで行う行動に「▶」が付きます（スカイアの飛行中は下記のとおりずれます）。

敵ごとの注意:

| 敵 | 注意 |
| --- | --- |
| スカイア | 「スキル」で飛び上がると、次のフェーズのビームはリストを消費せずに行います（飛行中はリストを進めません）。 |
| シーカー | 攻撃を持たないため、「攻撃」のフェーズは何もしません。 |
| エナー | 「スキル」は吸収できる仲間がいないとき（またはそのフェーズに吸収済みのとき）は何もしません。 |
| でかエナー | 「スキル」は HP がコスト（20）以下のときは何もしません。 |

シーカーが召喚したエナーには行動リストはありません（ランダム行動）。

## 保存

編集すると「CSVに保存 *」が押せるようになり、押すと CSV を上書きします。

- 1行目（クリア条件）は、クリア条件を変更したときだけ `種類, 値` の形で書き直します。変更していなければ元の文字列のまま残します。2行目（ヘッダー）は常に元のままです。
- 3行目以降は `Wall, 縦, 横` / `SlopeWall, 縦, 横, 角度` / `Unit, 縦, 横, 敵, レベル, 行動リスト` の形で書き直します。
  - 行動リストは `Attack/Skill/Attack` のように `/` 区切りで書きます。行動リストが空なら列ごと省略し、レベル 0 のときはレベルも省略します（行動リストがあるときはレベル 0 でも `0` を書きます）。
  - 行動リスト列の無い既存の CSV はそのまま読めます（全員ランダム行動）。
  - 行動リストを保存するとき、2行目（ヘッダー）に `Actions` が無ければ末尾に `,Actions` を足します。
- 読み込めなかった行（列不足・範囲外・重複など）がある場合は警告が出ます。そのまま保存するとその行は消えるので、先に Console の警告を見て直してください。
- 「変更を破棄」で CSV を読み込み直します。EnemyInfo.csv を書き換えたときは「EnemyInfo.csv を再読み込み」を押してください。
