# 敵の攻撃の点滅予告と防御

敵の攻撃時に出ていた防御QTEを廃止し、次の方式に変えました。

- 敵は攻撃アニメーション中に **赤く3回点滅** してから攻撃する（アニメーションイベント `StartAttackBlink(秒数)`）。
- 敵の攻撃アニメーションが始まってからダメージ処理が終わるまで、プレイヤーは **クリックで防御** できる（プレイヤーフェーズの「防御」行動とは別物）。
- 3回目の点滅（攻撃の瞬間）にプレイヤーが防御受付時間内なら、その攻撃を **完全に防御**（ダメージ 0）する。

## 点滅のタイミング

`StartAttackBlink(秒数)` を呼んだ時点を 0 秒、引数を `T` 秒とすると:

| 時刻 | 内容 |
|---|---|
| 0 〜 T/2 | 1回目: 軽く赤く染まって（前半）白へ戻る（後半） |
| T/2 〜 T | 2回目: 同上 |
| T | 3回目: 大きく赤く染まる。**同時に防御判定をして攻撃する**。その後 0.3 秒で白へ戻る |

色は `BaseUnitView` の Inspector で変えられます（`ColorUtility.TryParseHtmlString` 形式の文字列）。

| 項目 | 初期値 | 内容 |
|---|---|---|
| Attack Blink Light Color Code | `#FF9A9A` | 1・2回目の軽い赤 |
| Attack Blink Strong Color Code | `#FF1A1A` | 3回目の大きな赤 |

## 防御

| 項目 | 値 | 場所 |
|---|---|---|
| 防御受付時間 | 0.15 秒 | `EnemyAttackGuard.GuardWindow` |
| クールタイム | 0.3 秒 | `EnemyAttackGuard.Cooldown` |

- クリックすると 0.15 秒間だけ防御状態になり、プレイヤーが青く光ります（色は `PlayerView` の **Guard Flash Color Code**、初期値 `#7FB2FF`）。
- 防御状態が終わってから 0.3 秒間は次の防御を入力できません（連打しても 0.45 秒に1回）。
- 完全に防御すると、ダメージなし・「Guard!!」表示・SE `QTE_Perfect`・防御パーティクル（`PlayerView` の Defend Particle）が出ます。
- 防御できるのは通常攻撃と、スカイアのビーム（飛行中のスキル）です。

## 1. 攻撃アニメーションにイベントを追加する（必須）

攻撃する敵それぞれの攻撃クリップ（スカイアはビームのクリップも）で行います。

1. 攻撃クリップ（例: `Assets/Animation/<敵>/Attack.anim`）を Animation ウィンドウで開く。
   プレビュー対象に `BaseEnemy` / `FlyingEnemy` プレハブを選んでおくと Function の候補が出ます。
2. 点滅を始めたいフレームで **Add Event** を押す。
3. Inspector で **Function** に `StartAttackBlink` を選び、**Float** に「点滅を始めてから攻撃するまでの秒数」（例: `1.2`）を入れる。
4. 同じクリップにある **`ActiveAttack` のイベントは削除する**。
   残っていると `ActiveAttack` の時点で攻撃が進んでしまい、点滅の途中でダメージ処理が始まります。
5. 攻撃の見た目（剣を振り下ろす・弾が当たるなど）が、`StartAttackBlink` のフレーム + 秒数 の時刻に来るように調整してください。

`StartAttackBlink` を入れていないクリップは、これまでどおり `ActiveAttack` のタイミングで攻撃します（点滅なし）。
その場合の防御判定は、ダメージ処理の瞬間に防御受付時間内かどうかで行います。

対象の目安: ビルダー / スカイア（Attack と Beam） / ブースター / ブルート / エナー / でかエナー。シーカーは攻撃が無いので不要です。

## 2. 確認すること

- 敵の sprite の Color は死亡アニメーション（`dead.anim`）が動かしているため、Write Defaults が有効なステートでは Animator が毎フレーム既定の色を書き込み、点滅の色が消えます。
  点滅中は `Update` で色を反映していますが、Animator はその後に更新されるので、**攻撃ステート（スカイアは Beam も）の Write Defaults を OFF にする**などの設定が必要です。
- 点滅はスクリプトから `SpriteRenderer.color` の RGB だけを変えます（透明度は変えないので、死亡時のフェードとは干渉しません）。

## 3. 変わったこと（既存の仕組みへの影響）

- 防御QTE（`QTEKinds.Defend`）は削除しました。攻撃QTE（プレイヤーの一閃）はそのままです。
- 防御QTE中に `Time.timeScale = 0.001` にしていたスローは無くなりました。
- 被ダメージの倍率は、防御QTEの結果（大成功 0.2 / 成功 0.8 / 失敗 1.1）の代わりに、完全防御なら 0、それ以外は 1.0 です。
  プレイヤーフェーズの「防御」行動による半減は今までどおりです。
- 被ダメージ SE の出し分けは [UnitSoundEffect.md](UnitSoundEffect.md) を参照。
- 初回の QTE チュートリアル（`TutorialKinds.QTEAppear`）は攻撃QTEでだけ出ます。チュートリアル文に防御QTEの説明があれば直してください。
